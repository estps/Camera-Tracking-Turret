Dual-Axis AI Turret

This project combines computer vision, an ESP32 microcontroller, and dual-axis stepper motors to track physical targets in real-time.

Currently, this main branch serves as a placeholder and landing page. The active source code, including the Python bridge scripts, the ESP32 hardware firmware, and the YOLO AI implementation, will be populated here shortly.

Hardware Overview

ESP32 Microcontroller

Stepper Motors (Yaw and Pitch axes)

Custom Gear Reductions (e.g., 166:24 and 60:20)

USB Webcam (e.g., Logitech C270)

Software Stack

Python (OpenCV, PySerial)

Ultralytics YOLO (For object and human pose detection)

C++ / Arduino (For the ESP32 continuous motor driver)

Setup instructions, wiring diagrams, and usage documentation will be added to this file once the main codebase is uploaded to this branch.
